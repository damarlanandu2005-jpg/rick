## R2 (2026-11-23): storyboard, rough/hook animatic, independent judge, one-fix-round, G8
Owner "GO R2" (whole phase, one pass). Architecture unchanged; no new planning/camera/timing schema, no new renderer. Code: `tools/review.py` (+ G8 in `creative_gates.py`, G8 re-check in `approval.py`, stage `G1-G8` in `pipeline.py`).
- **R2A storyboard:** `review.py storyboard <ep>` runs the existing `render.mjs --storyboard`, then writes `creative/STORYBOARD.json`: stations derived from `camera_baked.json` (one per take/station, START = first rest frame, END = last), panel PNGs with sha1, `plan_sha1` + `baked_sha1`. Deterministic (no timestamps). Stale, wrong-plan, malformed, tampered or incomplete storyboards fail.
- **R2B animatic:** `review.py animatic <ep> [--step 3] [--hook-seconds 3]` runs the existing `render.mjs --animatic --step` (whole-film rough at every 3rd frame, each held 3 frames so it plays in real time) and trims the first 3 s as the hook. `creative/ANIMATIC.json` holds two labelled artifacts: `whole-film-rough` (frames 0..N-1) and `hook-partial` ("NOT a full-film review"). The frame set and video frame count are verified; a hook alone never satisfies G8.
- **R2C judge:** the judge is a fresh-context agent (Ricks `storyboard-judge` + `studio-director`; `review.py judge-brief` writes its brief). It supplies scores, rationales and fixes; `review.py judge-record` computes PASS/FAIL itself: every required panel (all storyboard panels) >= 8.5 and film-level and studio-director verdicts PASS.
